A geotechnical analysis answers a [check](../reference/glossary.md#check). It turns the [engineering geological model](../reference/glossary.md#egm) into a [geotechnical design model](../reference/glossary.md#gdm) for one structure and one check, with design values per layer, and verifies the limit state with an [analysis method](../reference/glossary.md#analysis-method).

| Analysis type | Checks it answers, for example |
| --- | --- |
| Stability | bearing resistance, sliding, overall stability of a slope or an excavation |
| Deformation | settlement, heave, deflection of a retaining wall |
| Groundwater flow | uplift, piping, hydraulic heave, drawdown around a dewatered pit |
| Dynamics | vibrations of machine foundations and from installing piles or sheet piles, liquefaction |
| Effects on existing structures | damage to nearby buildings from settlement or drawdown, deformation of an existing tunnel |

Each method page will say what the method calculates, which [geotechnical parameters](../reference/glossary.md#geotechnical-parameter) it needs, how detailed the ground model must be and how far it must reach, and which ground investigation delivers that.
