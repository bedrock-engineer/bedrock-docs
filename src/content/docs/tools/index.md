**Where this fits:** [Atlas](../index.md) › Tools

Every tool has a folder of the same shape: a tool page that says what it's for and where it shows up on these pages, then getting started, guides, examples and reference. For our own packages, all but the tool page come from the package's repository, at its release (see [Sources](../contributing/sources.md)). The analysis software for a particular check is listed on its structure hub instead, for example under Software on [Spread foundations](../structures/spread-foundations.md).

## Explain and explore

- [marimo](marimo/index.md): the [reactive notebook](../reference/glossary.md#reactive-notebook) that every notebook and [explorable explanation](../reference/glossary.md#explorable-explanation) on this site is written in. Start with the [Learn marimo](marimo/getting-started/index.md) tutorial.

## Ground investigation

- [cpt-anywidget](cpt-anywidget/index.md): our notebook viewers for [CPTs](../reference/glossary.md#cpt) and borehole logs, with an editable layer column.

## Calculate and report

- [SymEval](symeval/index.md): our own package that turns a formula and values with units into the steps of a [calculation report](../reference/glossary.md#calculation-report): the formula, the values substituted, the result.
